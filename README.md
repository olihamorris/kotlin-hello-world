# Overview

As a software engineer in training, I am learning the Kotlin language the Kaizen way, that is step by step, and every language starts with a small first program. This project is my first working Kotlin program. It confirms that my tools are set up correctly, and it gives me a base for the larger programs I will build next.

The software is a small Hello World program written in Kotlin. When it runs, it prints "Hello, World!" and then a second line that introduces me by name. It stores my name in a variable and joins it to the rest of the sentence.

My purpose in writing it is to check that Kotlin, IntelliJ IDEA and Git work together on my computer, and to learn the basic structure of a Kotlin program: the main function, a variable, and how output is printed.

# Development Environment

I wrote and ran the program in IntelliJ IDEA on Windows, using the Amazon Corretto 25 JDK. I used Git for version control and GitHub to publish the code.
